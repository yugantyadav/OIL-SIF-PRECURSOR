WHAT IS THIS PROJECT IN ONE LINE?
-----------------------------------
We help Oil India find hidden danger signs in daily safety reports and CCTV
camera footage BEFORE they become a serious injury or death. The computer
reads what happened, checks it against safety rules, gives a risk score,
and alerts the safety officer on the website and on their phone.

HOW IT WORKS (SIMPLE FLOW)
-----------------------------
1. A worker writes a report: "Oil leakage near drilling equipment" + where + who was in charge.
   OR a CCTV camera records a video.
2. The AI reads it / watches it and decides: Is this dangerous? How much? Why?
3. The system creates a proper report automatically (no need to pick risk manually).
4. If it is dangerous, the safety officer gets an instant alert on the website and phone.
5. Everything is saved in a diary that cannot be changed or deleted (for audit).

4. AI TEAM - The Smart Eye (1 person)
   Plain: They teach the computer to see danger in text and video.

   To Do for TEXT (already partly done):
   - Keep hybrid: TF-IDF model (sif_model.pkl) + 7 lexicon rules
     (6 IOGP rules + new Hydrocarbon Release for oil/gas leakage, boost to 0.82).
   - Ensure oil leakage now correctly gives High 82% (already fixed).

   To Do for CCTV VIDEO (new, detailed - must see everything):
   - PPE Detection: Teach YOLOv8 to see 8 items: helmet, safety vest, gloves,
     goggles, safety shoes, harness, mask, plus person. 640x640, confidence 0.45.
     Per zone PPE profile (Zone A needs helmet+vest). Output: helmet Yes/No + box.
   - Worker Identification: Use badge/ID OCR (simpler, more private than face).
     If no badge, use tracking ID (ByteTrack). Save worker_id + role.
   - Restricted-Zone Detection: Let officer draw a polygon on camera view (4 points).
     Check if worker foot-point is inside polygon (Shapely point_in_polygon).
     If inside and not authorized -> violation. Flash red overlay.
   - Unsafe Behavior / Proximity: If worker bbox is <50 pixels (~1 meter) from
     machinery ROI and stays >1 second -> proximity violation.
   - Fall and Suspected Injury: Use pose keypoints -> height/width flip +
     sudden velocity + dwell on ground >2 seconds + 5-frame window, confidence >=0.65.
     This triggers Critical.
   - Fire/Smoke (optional): Small classifier for tank farm zone only.
   - Severity Levels: Warning (missing helmet -> dashboard toast),
     Serious (zone intrusion/proximity -> supervisor alert + local warning),
     Critical (confirmed fall/fire/leak + temporal) -> site-wide alert.
   - Automatic Escalation: Detection -> verify (confidence + 2s) -> severity ->
     if Critical: push + speaker -> wait 60s for ACK -> if no ACK: escalate to HSE manager.
   - Supervisor Alerts: Fan-out to subscribed officers per site/zone via push.
   - Site-Wide Speaker/Alarm: Mock for demo: Frontend Audio() plays
     "Emergency Zone B, stop operations" + backend logs speaker_triggered. Real PA
     needs OIL electrical/network sign-off later.
   - Evidence/Video Recording: Save 30s before + 60s after clip + 3 screenshots + JSON
     (event type, time, camera, zone, worker, severity, bbox). Store in ./data/evidence/.
   - Predictive Safety: Combo logic: restricted entry + missing PPE + proximity
     = High-risk warning BEFORE a fall happens.
   - Also: Auto-generate 9-field incident report on every CCTV detection:
     What, Where, When, Why, How (sequence), Severity, People/objects,
     Corrective measures, Preventive measures, CCTV evidence + snapshot.
   - Plus: Calculate Site Risk Index: Frequency * Severity * Recency decay
     -> heatmap.
